# theokit-gateways — Architecture Hardening Roadmap

Not a greenfield inception: no Socratic interview and no SOTA peer clones — the milestones below are the audit's own 10-step migration plan grouped into shippable slices.

## Vision

Preserve the exemplary structure of the `theokit-gateways` monorepo (zero circular deps, SDK-agnostic core, strict barrel encapsulation) while paying down the **only** real debt the audit found: duplicated *knowledge*. Two shared primitives are extracted into `@theokit/gateway` core — a boundary-preferring text chunker and a configuration-error base — so a surrogate-pair edge-case fix or an error-contract change lives in **one** place, and adding an 11th gateway carries no split/error boilerplate. Restructuring only; behavior is preserved end-to-end.

## Problem

**Root problem:** The same boundary-preferring text-chunking algorithm is copy-pasted across **7 sites** (2 families + 1 legitimately-distinct telegram variant) and the `ConfigurationError` class body is copy-pasted verbatim across **8 packages**. This is DRY-of-knowledge duplication (~120–150 LOC): a single edge-case fix must be applied in 6 places, and an error-contract change touches 8 files. Two structural clarity nits compound it — `hooks/types.ts` hides the `HookExecutor` class, and the closed `MessageEvent` union is an undocumented OCP trade-off.

**Whose pain:** Maintainers of the gateway cluster — every duplicated site is a place a bug fix can be forgotten, and every new platform adapter re-copies the boilerplate.

## Users

- **Primary:** `@theokit` gateway maintainers (internal engineering, single team owning all 11 packages).
- **Secondary:** downstream consumers of `@theokit/gateway` (bot authors) — they benefit indirectly from a single `instanceof GatewayConfigurationError` contract and consistent chunking behavior.

## Scope

### In scope (V1 — required to call this hardening effort done)

- Extract `chunkText({limit, granularity, transformPart?})` into `@theokit/gateway/text/chunk.ts` and migrate the 6 duplicated split implementations to thin wrappers.
- Hoist a `GatewayConfigurationError` base into `@theokit/gateway/errors/config-error.ts` and repoint the 8 per-package `ConfigurationError` classes to extend it.
- Split `hooks/types.ts` into `hooks/executor.ts` (class) + `hooks/types.ts` (interfaces); re-point the barrel.
- Backfill missing pin tests (`split.test.ts` for discord; `errors.test.ts` for line/matrix/mattermost/sms) **before** any behavior-changing conversion.
- Record the closed `MessageEvent` union as an ADR and document the per-package type-file naming convention.

### Explicitly out of scope

- **Opening the `MessageEvent` closed union for OCP purity** — *why excluded:* it would trade compile-time exhaustiveness (which `defaultStrategy` and every `never`-check depend on) for runtime uncertainty. Pattern theater. Documented as an accepted trade-off (ADR), not fixed.
- **Force-unifying `gateway-telegram`'s markdown-aware split into the shared chunker** — *why excluded:* it is legitimately distinct knowledge (markdown-pair balancing); merging it would be accidental coupling, a DRY anti-pattern.
- **Any boundary rework, re-layering, or rewrite** — *why excluded:* the audit scored coupling/cohesion/structure ≥90%; there is nothing to restructure. All changes are additive-then-rewire.

> Items in this list are off-limits for V1. To reconsider, write a new roadmap revision — do not silently expand scope.

## Milestones

> Each milestone has a checkbox in its header. Flip `[ ]` → `[x]` as you complete it. Status lives in this document; no external tracker required. Milestone → migration-step mapping (report §10) noted per milestone.

### M0 — [ ] Walking skeleton: additive core primitives + safety net

**Objective:** Stand up the new core scaffolding (`chunkText`, `GatewayConfigurationError`, `hooks/executor.ts`) and backfill missing pin tests — all behavior-preserving, zero adapter rewiring yet.

**Definition of done (all must hold):**

- [ ] `packages/gateway/src/hooks/executor.ts` holds `HookExecutor`; `hooks/types.ts` holds interfaces only; barrel re-points; `pnpm --filter @theokit/gateway typecheck && test` green (step 1).
- [ ] `packages/gateway/src/text/chunk.ts` exports `chunkText({limit, granularity:"utf16"|"grapheme", transformPart?})` with golden tests in `packages/gateway/tests/chunk.test.ts`; exported from barrel (step 2).
- [ ] `packages/gateway/src/errors/config-error.ts` exports `GatewayConfigurationError` base; exported from barrel (step 3).
- [ ] `gateway-discord` inline `splitForDiscord` (adapter.ts:194) extracted to `split.ts` with a new pin `split.test.ts` (step 4).
- [ ] `errors.test.ts` added for `line`/`matrix`/`mattermost`/`sms` capturing current name/prefix/`instanceof` (step 5).

**Dependencies:** none (this is the foundation).

**Top risks:**

1. `chunkText` API too narrow to cover both families (utf16 surrogate guard + grapheme walk) — mitigate by writing golden tests from the existing 6 copies' outputs first.
2. Barrel re-point after the hooks split silently changes a public export shape — mitigate by asserting the 30 named exports are unchanged.

### M1 — [ ] Migrate split consumers to `chunkText`

**Objective:** Convert the 6 duplicated `split.ts` implementations to thin wrappers over core `chunkText`, one package at a time, guarded by golden tests.

**Definition of done:**

- [ ] findCutPoint-family (`slack`/`whatsapp`/`teams`/`discord`) `split.ts` converted to thin `chunkText` wrappers; each package's `split.test.ts` golden output identical before/after (step 6).
- [ ] Intl.Segmenter-family (`line`/`sms`) `split.ts` converted to grapheme wrappers; golden output identical before/after (step 7).
- [ ] `gateway-telegram/src/split.ts` left **unchanged** (distinct markdown split — verified untouched).

**Dependencies:** M0 (requires `chunkText` + discord pin test).

**Top risks:**

1. Unifying the algorithm shifts break points on ties (behavior `minor`) — mitigate by one-package-at-a-time conversion with before/after golden comparison; revert that single file on any drift.
2. Per-platform MAX constants (4000/4096/8000/2000) mis-mapped — mitigate by asserting each wrapper passes its package's exact limit.

---

### M2 — [ ] Consolidate the configuration-error base

**Objective:** Repoint the 8 verbatim `ConfigurationError` classes to extend the core `GatewayConfigurationError`, preserving name, message prefix, and `instanceof` behavior.

**Definition of done:**

- [ ] `email`/`line`/`matrix`/`mattermost`/`slack`/`sms`/`teams`/`whatsapp` `errors.ts` `ConfigurationError` extends the core base; package-specific subclasses (`SDKNotInstalledError`, etc.) stay local (step 8).
- [ ] Each package's `errors.test.ts` (name, prefix, `instanceof`) assertions identical before/after.
- [ ] ~7 duplicated class bodies removed; a single `instanceof GatewayConfigurationError` holds across all gateways.

**Dependencies:** M0 (requires core base + the 4 backfilled `errors.test.ts`).

**Top risks:**

1. `instanceof`/message assertions in downstream consumers break if `name` or prefix drifts — mitigate by keeping strings byte-identical, guarded by the pin tests from M0.
2. Subclass options interface diverges from the base — mitigate by having the base carry the shared `code`/`detail` fields and packages extend only.

---

### M3 — [ ] Document decisions + final green gate

**Objective:** Record the accepted architectural trade-offs and land the full-suite verification.

**Definition of done:**

- [ ] `docs/adr/0001-message-event-closed-union.md` records the closed-union decision (why exhaustiveness beats OCP purity here) (step 9).
- [ ] The per-package type-file naming convention (`types.ts` = public shapes vs `backend-types.ts` = seam) documented (step 9).
- [ ] Final gate green: `pnpm -r typecheck && pnpm -r test && pnpm -r build && pnpm check`; `madge --circular` still clean; no new `exports` subpaths (step 10).
- [ ] Validation checklist (report §11) fully checked.

**Dependencies:** M1, M2 (all code changes landed before the final gate + ADRs).

**Top risks:**

1. The final full-suite build surfaces a cross-package type regression missed per-package — mitigate by running `pnpm -r` (all packages) not just filtered.
2. ADR drifts from the code decision over time — mitigate by pointing `message-event.ts` docstring at the ADR path.
