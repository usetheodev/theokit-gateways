# Release model — tag on develop

This repo has **no `main` branch**. v1.7.0, v1.7.1 and v1.8.0 are all on the
develop line, so releases are cut by **tagging `develop` directly**, not through
a `develop → main` PR. See [release model](/releases/release-model.md) for why
that matters when reading the cycle rules, which assume the PR path.

# npm publishing was NOT performed

This is a **repo-level v-tag marker only**. It did not run Changesets, so no npm
package was version-bumped or published. Consumers pulling from npm did not
receive the hardening code from this tag — that took the separate
[`@theokit/gateway@0.5.0` publish](/releases/theokit-gateway-0-5-0-npm.md). The
deferral was an explicit decision, not an oversight.
